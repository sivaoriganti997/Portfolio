# Siva Origanti — Trendy DevOps Portfolio

Modern single-page portfolio for GitHub Pages.

## Files

- `index.html`
- `style.css`
- `script.js`
- `resume.pdf`

## GitHub Pages

Create a repository such as:

`<your-github-username>.github.io`

Upload all files to the `main` branch.

Then:

**Settings → Pages → Deploy from a branch → main → /(root)**

## Customize

- Replace `resume.pdf` with your latest resume.
- Update the LinkedIn URL if required.
- Add your GitHub URL when you have one.
- Edit project descriptions in `index.html`.
